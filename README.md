# CLI学習記録アプリ

Pythonで作成した、ターミナル上で学習記録を管理できるCLIアプリです。

学習した日付、科目、学習時間を登録し、記録の一覧表示、削除、学習時間の集計ができます。記録はJSONファイルへ自動保存されるため、アプリを終了した後もデータが残ります。

## 主な機能

- 学習日、科目、学習時間の登録
- 登録した学習記録の一覧表示
- 番号を指定した記録の削除
- 全記録の合計学習時間の表示
- 指定した科目の合計学習時間の表示
- JSONファイルへの自動保存
- 保存済み記録の読み込み
- 日付、科目、学習時間の入力チェック
- 不正な削除番号の例外処理
- 終了時のデータ保存

## 実行環境

- Python 3.14.6
- macOS
- 外部ライブラリなし

このアプリでは、Pythonの標準ライブラリのみを使用しています。そのため、`pip install`による外部ライブラリのインストールは必要ありません。

## 実行方法

### 1. プロジェクトフォルダーへ移動する

ターミナルを開き、`study_record_app`フォルダーへ移動します。

```bash
cd study_record_app
```

### 2. アプリを起動する

```bash
python main.py
```

環境によっては、次のコマンドを使用します。

```bash
python3 main.py
```

## 操作方法

アプリを起動すると、次のメニューが表示されます。

```text
===== 学習記録アプリ =====
1. 記録を追加
2. 記録を一覧表示
3. 記録を削除
4. 合計時間を表示
5. 科目別の合計時間を表示
6. 終了
番号を選択してください：
```

利用したい機能に対応する、`1`から`6`の番号を入力します。

範囲外の番号や文字列を入力した場合は、次のメッセージが表示されます。

```text
1から6を選択してください
```

## 各機能の説明

### 1. 記録を追加

次の3つの情報を入力します。

- 日付
- 科目
- 学習時間

日付は`YYYY-MM-DD`形式で入力します。

```text
2026-09-12
```

学習時間は、1以上の整数を分単位で入力します。

```text
60
```

入力例は次のとおりです。

```text
日付をYYYY-MM-DD形式で入力してください：2026-09-12
科目を入力してください：Python
勉強時間を入力してください：60
記録が完了しました
```

追加した記録は、すぐにJSONファイルへ保存されます。

### 2. 記録を一覧表示

登録済みの学習記録を番号付きで表示します。

```text
1.
日付：2026-09-12
科目：Python
勉強時間：60分
```

登録されている記録がない場合は、次のメッセージが表示されます。

```text
記録がありません
```

### 3. 記録を削除

最初に登録済みの記録一覧が表示されます。

削除したい記録の番号を入力すると、対応する記録が削除されます。

```text
削除する番号を入力してください：1
削除しました
```

記録番号には、一覧の左側に表示された番号を指定します。

整数以外や存在しない番号を入力した場合は、エラーメッセージが表示されます。

削除後の記録は、すぐにJSONファイルへ保存されます。

### 4. 合計時間を表示

登録されているすべての記録の学習時間を合計します。

```text
合計学習時間：150分
```

### 5. 科目別の合計時間を表示

科目名を入力すると、指定した科目の学習時間だけを合計します。

```text
科目を選択してください：Python
Pythonの合計時間：120分
```

指定した科目の記録がない場合は、次のメッセージが表示されます。

```text
その科目の記録はありません
```

現在の実装では、科目名を完全一致で検索します。

例えば、次の文字列は別の科目として扱われます。

```text
Python
python
PYTHON
```

### 6. 終了

現在の学習記録をJSONファイルへ保存して、アプリを終了します。

```text
終了します
```

## ファイル構成

```text
study_record_app/
├── main.py
├── models.py
├── operations.py
├── storage.py
├── README.md
└── data/
    └── study_record.json
```

`data`フォルダーと`study_record.json`は、必要に応じてアプリによって作成されます。

## 各ファイルの役割

### `main.py`

アプリ全体の進行を担当します。

主な役割は次のとおりです。

- 保存済み記録の読み込み
- メニューの表示
- 利用者からの番号入力
- 選択された機能の呼び出し
- 終了時の保存
- アプリの起動

次の記述により、`main.py`が直接実行された場合だけアプリが起動します。

```python
if __name__ == "__main__":
    main()
```

### `models.py`

学習記録1件を表す`StudyRecord`クラスを定義しています。

1件の学習記録は、次の3つの情報を持ちます。

- `date`：学習日
- `subject`：科目
- `study_time`：学習時間

`to_dict()`メソッドを使い、`StudyRecord`オブジェクトをJSONへ保存できる辞書へ変換します。

### `operations.py`

学習記録に対する操作を担当します。

定義されている主な関数は次のとおりです。

- `add_record()`：記録を追加する
- `show_records()`：記録を一覧表示する
- `delete_record()`：指定した記録を削除する
- `total_time()`：すべての学習時間を合計する
- `subject_total()`：指定した科目の学習時間を合計する

日付、科目、学習時間、削除番号の入力チェックも担当します。

### `storage.py`

学習記録の保存と読み込みを担当します。

主な役割は次のとおりです。

- JSONファイルへの保存
- JSONファイルからの読み込み
- オブジェクトから辞書への変換
- 辞書からオブジェクトへの変換
- JSONファイルの保存場所の管理
- `data`フォルダーの作成
- ファイルが存在しない場合の例外処理
- JSONの形式が壊れている場合の例外処理

### `data/study_record.json`

登録した学習記録が保存されるJSONファイルです。

保存されるデータの例は次のとおりです。

```json
[
    {
        "date": "2026-09-12",
        "subject": "Python",
        "study_time": 60
    }
]
```

JSONファイルが存在しない場合は、空の記録一覧からアプリが開始されます。

## データの流れ

記録を追加すると、次の順番で処理されます。

```text
利用者が情報を入力
        ↓
入力内容を検証
        ↓
StudyRecordオブジェクトを作成
        ↓
記録のリストへ追加
        ↓
オブジェクトを辞書へ変換
        ↓
JSONファイルへ保存
```

アプリを起動すると、次の順番で記録が復元されます。

```text
JSONファイルを読み込む
        ↓
JSONから辞書を取得
        ↓
辞書からStudyRecordオブジェクトを作成
        ↓
記録のリストへ追加
        ↓
保存済み記録をアプリ内で使用
```

## 入力チェック

### 日付

次の入力を拒否します。

- 空欄
- スペースだけの入力
- `YYYY-MM-DD`形式ではない入力
- 実在しない日付

入力できない例：

```text
2026/09/12
2026-02-30
あいうえお
```

入力できる例：

```text
2026-09-12
```

### 科目

次の処理を行います。

- 空欄を拒否
- スペースだけの入力を拒否
- 入力値の前後にある空白を削除

### 学習時間

次の入力を拒否します。

- 文字列
- 小数
- 0
- 負の整数

入力できない例：

```text
Python
30.5
0
-20
```

入力できる例：

```text
30
60
120
```

1以上の整数が入力されるまで、入力を繰り返します。

### 削除番号

次の入力を拒否します。

- 整数以外の入力
- 0以下の番号
- 記録件数を超える番号

## 例外処理

このアプリでは、次の例外を処理しています。

### `ValueError`

次の場合に処理します。

- 日付の形式が正しくない
- 学習時間が整数ではない
- 学習時間が0以下
- 削除番号が整数ではない

### `IndexError`

存在しない記録番号が指定された場合に使用します。

### `FileNotFoundError`

初回起動時など、JSONファイルが存在しない場合に処理します。

この場合は、空の記録一覧からアプリを開始します。

### `json.JSONDecodeError`

JSONファイルの内容が正しいJSON形式ではない場合に処理します。

この場合は、利用者へ次のメッセージを表示し、空の記録一覧から開始します。

```text
保存ファイルの内容が壊れています
```

## データの保存

記録を追加または削除すると、変更後の記録がJSONファイルへ自動保存されます。

アプリを再起動したときは、JSONファイルから保存済みの記録が読み込まれます。

保存場所は`pathlib`を使って、`storage.py`が置かれているフォルダーを基準に決定しています。

```text
storage.pyがあるフォルダー
        ↓
dataフォルダー
        ↓
study_record.json
```

これにより、アプリを実行したときのターミナルの位置に左右されにくい保存先にしています。

## 工夫した点

- 学習記録1件を`StudyRecord`クラスで表現しました
- 複数の学習記録をオブジェクトのリストとして管理しました
- JSONへ保存する前に、オブジェクトを辞書へ変換しました
- JSONの辞書から`StudyRecord`オブジェクトを復元しました
- 日付の形式だけでなく、実在する日付かどうかも検証しました
- 学習時間が1以上の整数になるまで再入力を求めるようにしました
- 不正なデータが保存されないように入力値を検証しました
- 記録の追加と削除の直後に自動保存するようにしました
- クラス、操作、保存、メニューを別々のPythonファイルへ分割しました
- `pathlib`を使い、実行場所に左右されにくい保存先を設定しました
- `if __name__ == "__main__":`を使い、直接実行された場合だけアプリが起動するようにしました
- JSONファイルが存在しない場合や壊れている場合でも、アプリがすぐに停止しないようにしました
